# AdminMarket

Aplicación web para la gestión de productos, inventario, ventas y ganancias de negocios.

## 🚀 Tecnologías

- **HTML5** semántico
- **Tailwind CSS** (vía CDN con configuración extendida y fuente Inter)
- **JavaScript** modular para navegación interactiva y validación de formularios

## 📁 Estructura del Proyecto

```text
AdminMarket/
├── index.html                  # Página principal (Landing Page)
├── index.js                    # Lógica del menú responsive
├── styles.css                  # Directivas base de Tailwind
├── iniciodesesion/
│   ├── index.html              # Pantalla de inicio de sesión
│   ├── index.js                # Validación y almacenamiento local
│   └── inicio.css              # Directivas base de Tailwind
├── registrar/
│   ├── index.html              # Pantalla de creación de cuenta
│   ├── index.js                # Validación de contraseñas y registro
│   └── styles.css              # Directivas base de Tailwind
└── img/                        # Recursos e imágenes
```

## 💻 Cómo ejecutar

1. Abre el proyecto en **Visual Studio Code**.
2. Haz clic derecho en `index.html` y selecciona **Open with Live Server** (o usa el botón Go Live en el puerto 5502).
3. Todas las clases y estilos de Tailwind CSS funcionan de forma instantánea sin necesidad de pasos de compilación.
